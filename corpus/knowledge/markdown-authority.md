# Markdown and Git are the knowledge authority

VAWS knowledge is authored as Markdown. A public document is identified by its
repository path and Git commit. OpenViking provides retrieval over that content;
its index is a derived representation that can be rebuilt.

Local candidate and project documents remain separate from published shared
versions. A failed shared update must leave the previously active version
available and preserve both local layers. Checksums verify release integrity;
they do not replace the source Git identity or prove the technical claims in
a document.
